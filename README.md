# Dc Pro Painting

Website for Dc Pro Painting, painters and decorators in Dublin. *Keeping the Bay Beautiful.*

A single static page (`index.html` + `img/`), no build step. Open `index.html` in a browser, or publish with GitHub Pages (Settings → Pages → Deploy from branch `main`, folder `/`).
